## Added

### Install Dovik from npm

Install the same native Dovik 1.0.0 binaries on Windows x64, Linux x64, macOS x64, or macOS arm64 with `npm install --global dovik`. The npm package exposes `dovik` and `dovikd` without replacing or configuring GitHub CLI.
