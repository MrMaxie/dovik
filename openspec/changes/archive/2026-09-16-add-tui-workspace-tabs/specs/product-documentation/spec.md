## ADDED Requirements

### Requirement: Document TUI workspace navigation

The operator documentation SHALL identify Processes, Identity, and Personas as top-level TUI workspaces, explain left and right arrow navigation, and retain the existing direct identity shortcut and process controls.

#### Scenario: Learn TUI navigation

- **WHEN** a user reads the CLI and TUI guide
- **THEN** the guide explains the three tabs and their keyboard navigation
- **AND** distinguishes workspace switching from selection inside a workspace
