---
title: Updates
description: Update npm, portable archives, the container image, or Scoop while preserving private state.
---

## npm

Update the global package normally. npm selects the native package for the current platform and updates `dovik` and `dovikd` together.

```console
npm install --global dovik@latest
```

The npm package does not replace or configure your `gh` command.

## Portable archives

Download the new archive for the same platform, verify its checksum and attestation, stop `dovikd`, replace the binaries together, then restart the daemon. `dovik` and `dovikd` must report the same version.

Private registry and identity state is stored outside the installation directory and is not removed when binaries are replaced. Keep a backup appropriate to your workstation before a major upgrade.

## Scoop

Use normal Scoop update and uninstall commands. The manifest updates `dovik` and `dovikd` together. It does not install or activate the optional `gh` proxy.

## Container

Pull the exact version tag before moving a deployment. Floating tags are provided for convenience, but an exact tag or digest is the reproducible choice.
