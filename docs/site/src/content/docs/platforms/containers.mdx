## Historical daemon image

The Linux amd64 image published with Dovik 1.0.0 remains available as a historical artifact. New releases do not publish a GHCR image. Build the repository Dockerfile at an exact revision if you need a containerized daemon for development or verification.

A containerized daemon controls only processes inside its container. Mounting host process or container-engine control surfaces would violate the supported boundary.

## Isolated agent sessions

Docker and Podman are optional adapters for project identity isolation. Dovik starts the agent with a private stdio bridge, no exposed control port, no operator credentials, and no access to the engine socket. The requested adapter must already be installed and prepared by the operator.

Docker and Podman acceptance is tested separately. Availability or success of one engine does not establish support for the other.
