---
title: Linux
description: Run Dovik natively on Linux x64 and use containers for isolated agent sessions.
---

Install from npm or use `dovik-v1.1.0-linux-x64.tar.gz` for a native daemon and clients. Dovik creates a private Unix Domain Socket under `XDG_RUNTIME_DIR` when set, or a private per-user temporary directory otherwise. It uses a separate process group for each managed runtime.

Native identity isolation requires an operator-provisioned unprivileged user with access to the project and its parent directories. The account must not have write access to Docker or Podman sockets.

Docker and Podman remain supported adapters for isolated agent sessions. Dovik 1.1.0 does not publish a new daemon image.
