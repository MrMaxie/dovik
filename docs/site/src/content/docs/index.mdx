## Stop guessing which terminal owns the app.

<div class="dovik-capabilities">
  <article><h3>Register intent.</h3><p>Projects define the processes Dovik may supervise without exposing environment values to clients.</p></article>
  <article><h3>Control the whole process tree.</h3><p>Start, stop, and restart through the daemon instead of signaling guessed process IDs.</p></article>
  <article><h3>Share status and output.</h3><p>CLI, TUI, and MCP clients read the same current runtime and bounded stdout and stderr events.</p></article>
  <article><h3>Govern project identity.</h3><p>Personas align Git authors and GitHub accounts without changing the globally active `gh` account.</p></article>
</div>

</section>

<section class="dovik-home-section">

<p class="dovik-kicker">Responsibility boundary</p>

## Dovik supervises processes. It does not route traffic.

Dovik does not provide DNS, HTTPS, reverse proxying, domains, remote execution, scheduling, or container orchestration. Cadder remains an independent future option for endpoint allocation.
